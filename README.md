# Game idea: Touhou: Doubled Down [東方：ダブルダウン]
Concept: A fanmade touhou game where you have to dodge incoming bullet attacks. Use your dodging skills to evade the bullets! Again, this is a touhou fanmade game, so it is lightweight and art assets are minimal (as this is my first pygame game!).
> Inspiration: Touhou franchise

## Controls
Z - Select, Confirm, Interact

X - Bombs (and only bombs)

Left Shift - Focus mode (player's movements became slower by HALF)

Arrow keys (→, ←, ↑, ↓) - move

> [!NOTE]
> The game runs best at 120+ FPS! Although, you can technically play it at 60 FPS, but things might break! (60 FPS is verified to work but with lag).

You should definitely check out changelog.md for versions that were previously released, or to see what has changed!
